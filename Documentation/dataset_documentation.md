# Dokumentasi Dataset Prediksi Beban Listrik (Electricity Demand)

Dokumentasi ini memberikan penjelasan _Feature Dictionary_ untuk dua dataset terpisah yang dihasilkan `(dataset_daily_processed.csv` dan `dataset_monthly_processed.csv)`. Seluruh data pendukung (Temperatur, Cuaca, Makroekonomi, Hari Libur) diekstrak secara historis _(real-world data)_, sedangkan nilai sasaran (Demand) diekstrapolasi matematis berdasarkan Data Total BPS dengan prinsip Fisika Dasar dan Dinamika Pekerjaan.

---

## 1. Dataset Harian (`dataset_daily_processed.csv`)

Dataset ini digunakan untuk menangkap pola jangka pendek seperti aktivitas akhir pekan, cuaca ekstrem, dan jadwal kalender masyarakat.

| Nama Kolom                     | Tipe Data | Representasi Fisik & Deskripsi                                                                                                                                              | Sumber Data / Asal Usul                                                                                                                                            |
| :----------------------------- | :-------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`Date`**                     | Datetime  | Tanggal kejadian yang dicatat dalam format `YYYY-MM-DD`. Membantu algoritma Time Series merekam kronologi historis.                                                         | _Generated Time-Index_ (2018-2023)                                                                                                                                 |
| **`Demand_MWh`**               | Float     | **(Target Prediksi)** Konsumsi beban kelistrikan kumulatif untuk hari tersebut di dalam lingkup Indonesia, diukur dalam satuan Megawatt-hour (MWh).                         | Diturunkan dari **BPS (Total Tahunan)**. Diskalakan mulus harian melalui _time-interpolation_ kurva tahunan, dialokasi via bobot suhu/akhir pekan, lalu disuntik **noise stokastik** (±5% multiplikatif + ~3% aditif Gaussian) untuk mensimulasikan dinamika kelistrikan riil. |
| **`Day_of_Week`**              | Integer   | Penanda hari dalam 1 pekan. `0` = Senin hingga `6` = Minggu. Mengajarkan pola konsumsi beban hari kerja versus beban akhir pekan. | Kalkulasi dari kolom `Date`.                                                                                                                                       |
| **`Is_Weekend`**, **`Is_Holiday`** | Integer   | Identifikasi biner Sabtu/Minggu (1/0) dan Hari Libur Nasional (1/0) di mana aktivitas perkantoran/manufaktur drop. | Filter Kalender & **API (guangrei/Json-Indonesia-holidays)**. |
| **`Month`, `DayOfYear`, `WeekOfYear`** | Integer  | Penanda posisi tanggal di dalam setahun, mendefinisikan fase *Seasonality* tahunan dan pergerakan bulan. | Kalkulasi dari kolom `Date`. |
| **`Trend`**                    | Integer   | Nilai penanda lintasan (Hari ke-N sejak 2018-01-01), menangkap rasio elektrifikasi/pertumbuhan pelanggan jangka panjang. | Kalkulasi dasar `Date`. |
| **`Avg_Temp`**, **`Rainfall`** | Float     | Temperatur harian (°C) penggerak _Cooling Demand_ dan Curah Hujan (mm) pembatas visibilitas cuaca ekstrem. | Kaggle **(`climate_data.csv`)**. |
| **`Temp_Lag_1`**               | Float     | Suhu H-1. Fitur pengukur retensi panas inersia bangunan. | Feature Engineering dari `Avg_Temp`. |
| **`Lag_1`, `Lag_2`, `Lag_7`, `Lag_14`, `Lag_30`** | Float     | Jejak _Demand_MWh_ mundur 1, 2, 7, 14, dan 30 hari. Fitur esensial _Auto-Regressive_ mendeteksi aktivitas kronologis masyarakat.                | Feature Engineering dari `Demand_MWh`.                                                                                                                             |
| **`Rolling_7`, `Rolling_14`, `Rolling_30`** | Float     | Rata-rata pergerakan pemakaian listrik sepanjang 1, 2, dan 4 minggu. Berfungsi merekam gelombang pergerakan tren *smoothed* untuk Machine Learning.                                                   | Feature Engineering dari `Demand_MWh`.                                                                                                                             |

## 2. Dataset Bulanan (`dataset_monthly_processed.csv`)

Dataset ini diperuntukkan untuk menangkap esensi pola ekonomi makro berskala masif dan pertumbuhan negara jangka panjang.

| Nama Kolom             | Tipe Data | Representasi Fisik & Deskripsi                                                                                                                                                                                                                          | Sumber Data / Asal Usul                                                     |
| :--------------------- | :-------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------- |
| **`Year`**             | Integer   | Tahun pencatatan energi listrik historis.                                                                                                                                                                                                               | _Generated Time-Index_ (2018-2023)                                          |
| **`Month`**            | Integer   | Siklus periode Musim per bulan dalam rentang 1-12. Berfungsi sebagai landasan pengikat _Seasonality_.                                                                                                                                                   | _Generated Time-Index_.                                                     |
| **`Demand_GWh`**       | Float     | **(Target Prediksi)** Total Agregat konsumsi daya seluruh provinsi di Indonesia dalam 1 bulan kalender (Satuan Gigawatt-hour). Mewarisi noise stokastik dari agregasi harian.                                                                                                                          | Rekapitulasi file **BPS (Listrik yang didistribusikan per tahun)** via alokasi harian + noise.         |
| **`GDP`**              | Float     | _Gross Domestic Product_ alias angka kekuatan finansial negara dalam pecahan Miliar USD (Billions USD). Jika daya beli makmur, daya serap kelistrikan berfluktuasi positif.                                                                             | Bank Dunia / World bank **(`API_IDN_DS2...csv`)** (Kolom `NY.GDP.MKTP.CD`). |
| **`Population`**       | Float     | Populasi agregat masyarakat di Indonesia. Mewakili _Base-Load_ dari kebutuhan energi esensial rumah tangga yang harus dipenuhi tiap bulannya.                                                                                                           | Bank Dunia / World bank **(`API_IDN_DS2...csv`)** (Kolom `SP.POP.TOTL`).    |
| **`Manufacturing_VA`** | Float     | Nilai tambah manufaktur konstan 2015 US$ (_Manufacturing Value Added_). Mewakili aktivitas produksi riil pabrik berat sebagai pendorong mutlak beban dasar *Base-Load* sistem ketenagalistrikan nasional. | Bank Dunia / World bank **(`API_IDN_DS2...csv`)** (Kolom `NV.IND.MANF.KD`). |
| **`Avg_Temp`**         | Float     | Rata-rata iklim/panas terakumulasi selama satu bulan kalender. Data ini memberikan informasi musim pada AI (Kemarau dsb).                                                                                                                               | Dataset Historis Kaggle **(`climate_data.csv`)**.                           |
| **`Lag_1`, `Lag_12`**  | Float     | Indeks beban pada periode 1 bulan yang lalu, serta 1 tahun penuh yang lalu. Diperuntukkan untuk menangkap perbandingan _Year-on-Year / YoY_.                                                                                                            | Feature Engineering dari `Demand_GWh`.                                      |
| **`Rolling_12`**       | Float     | Garis haluan parameter konsumsi satu tahun tanpa dipengaruhi fluktuasi bulan musiman _(12-month Moving Average)_.                                                                                                                                       | Feature Engineering dari `Demand_GWh`.                                      |

---

**Catatan untuk Penjurian Hackathon:** Dataset ini masuk ke kategori _Synthesized Organic Dataset_. Atribut-atribut independen (X) murni menggunakan entri real historis, sedangkan nilai dependen/target (Y) diturunkan dari total tahunan BPS melalui alokasi proporsional bobot harian. Untuk **menghindari Target Leakage** (di mana model hanya merekayasa balik formula deterministik alih-alih belajar pola konsumsi nyata), lapisan **noise stokastik Gaussian** diterapkan pada target — mencakup variasi multiplikatif ±5% dan aditif ~3%. Ini mensimulasikan ketidakpastian dunia nyata (perilaku manusia, variasi cuaca mikro, aktivitas industri acak) sehingga model AI benar-benar belajar _generalisasi_ dan bukan sekedar menghafal rumus matematis internal.
